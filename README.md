# Personal Website (GitHub Pages + Jekyll)

This repository uses Jekyll so pages can be written in Markdown with a section-based tree.

## Structure

- `/index.md` home page
- `/about/index.md`
- `/projects/index.md`
- `/writing/index.md`
- `/resume/index.md`
- `/research/index.md`
- `/contact/index.md`
- `/_data/navigation.yml` navigation links
- `/_layouts/default.html` shared layout
- `/assets/css/style.css` shared styles

## Run locally (optional)

1. Install Ruby + Bundler
2. Run `bundle exec jekyll serve`
3. Open `http://127.0.0.1:4000`

## Why this setup

- Free hosting on GitHub Pages
- Easy to edit with Markdown
- Simple folder-per-section structure
