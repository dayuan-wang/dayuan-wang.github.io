# Website Restructure

## Problem

The site started as a single page, which made it difficult to expand and maintain.

## Approach

- Moved to GitHub Pages + Jekyll
- Added section landing pages with child pages
- Centralized shared layout, styles, and navigation

## Outcome

The site is now easier to update and scale without rewriting structure each time.
